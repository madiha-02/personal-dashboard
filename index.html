About Me

Who I am

Hi, I'm Madiha — a Software Developer based in Mapusa, Goa, who likes building things that work smoothly on both the front end and the systems behind it. My focus is React and React Native, but day to day that stretches into Next.js, TypeScript, and the backend APIs that feed them.

At my current job I ship features across the whole stack: server-rendered pages, video playback, subscription billing, accessibility, localization, a mobile app that shares almost all of its code with the web app, and the CI/CD pipeline that ships it all. I like the kind of problem where "make it work" and "make it work well" are the same requirement.

Outside of assigned work, I build small full-stack side projects to learn new corners of the stack — see the tab. This site itself is one of them: no framework, no build step, just HTML, CSS and JavaScript, hosted for free.
